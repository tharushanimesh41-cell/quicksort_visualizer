# Quicksort Visualizer

Here is a quicksort visualizer made to get a better understanding of the algorithm. The bars will move in real time.

Live here: https://tharushanimesh41-cell.github.io/quicksort_visualizer/

## What it does
Draws the steps of quicksort.
- Array speed can be changed, new arrays can be generated
Performs pivot and partitioning.Carries out pivot and partitioning.

## Built with
No Framework, just HTML, CSS and JavaScript!

## How to run
Just open index.html
